# Прыг-Скок

Платформер в духе игр для Денди, сделанный как Telegram Mini App.
Вся графика и звуки нарисованы и сгенерированы в коде, файлов из оригинальных игр здесь нет.

## Что есть

- Один уровень: монеты, бонус-блоки, кирпичи, трубы, лестницы, ямы и флаг в конце.
- Жуки-враги: на них можно прыгать сверху.
- Ягода делает героя большим: он ломает кирпичи и переживает одно касание врага.
- Счёт, монеты, жизни, таймер и рекорд (хранится на устройстве).
- Управление как на джойстике Денди: ◀ ▶, A (прыжок), B (бег, а с огненной силой ещё и выстрел), ТУРБО A и ТУРБО B. Клавиатура: ← →, A: Z/пробел, B: X/Shift, турбо A: A, турбо B: S.
- Внутри Telegram: разворот на весь экран и вибрация при прыжках и ударах.

## Структура

- `web/` — сама игра (статический сайт): `index.html`, `style.css`, `game.js`.
- `web/lib/phaser.min.js` — движок [Phaser 3.80.1](https://phaser.io) (лицензия MIT, `web/lib/phaser-LICENSE.md`).
- `.github/workflows/pages.yml` — публикация папки `web/` на GitHub Pages при пуше в `main`.

## Запуск локально

```sh
cd web
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Подключение к Telegram

1. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
2. После пуша в `main` игра будет доступна по адресу `https://admin2vitaplus.github.io/tg-mario/`.
3. В @BotFather: `/mybots` → ваш бот → Bot Settings → Menu Button → укажите этот адрес.
   Либо `/newapp`, чтобы у игры была своя ссылка `t.me/<бот>/<имя>`.

Токен бота в репозиторий не кладётся. Если понадобится серверная часть, токен хранится в `.env` (он в `.gitignore`) или в секретах хостинга.
